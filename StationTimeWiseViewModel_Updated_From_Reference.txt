The Station Wise page below follows the same working pattern.

IMPORTANT DESIGN
----------------
1. Apply Filter:
   - Calls database.
   - Loads ALL stations.
   - Loads ALL passenger data.
   - Creates ALL stacked-bar series once.
   - First 4 stations are selected by default.
   - Only the selected station values are shown.

2. Station selection:
   - DOES NOT call database.
   - Uses the already loaded/original series values.
   - Changes only the visible values and X-axis labels.
   - Therefore selecting/unselecting stations is fast.

3. The complete series remain in memory.
   - We do not recreate the database data.
   - We only replace the Values collection of each stacked series.

4. Station selection is updated when the MultiSelectComboBox closes,
   matching the reference page. This prevents rebuilding the chart for
   every single checkbox click while the dropdown is open.

5. The Name property remains on each series because the chart legend
   needs it. Tooltip text is separately formatted.

        // ================================================================
        // DATABASE LOAD
        // ================================================================

        public void LoadAsync()
        {
            ShowBusyCursor = true;

            try
            {
                int DirectionMode =
                    UplineMode ? 0 : 1;

                /*
                 * ========================================================
                 * 1. GET COMPLETE STATION AXIS DATA
                 * ========================================================
                 */
                DataTable StationAxiesTable =
                    _foreignServerDataMapper
                        .GetStationAxisAsync(
                            CorridorsFilterSelectedIndex + 1,
                            DirectionMode);

                /*
                 * ========================================================
                 * 2. GET COMPLETE PASSENGER DATA
                 * ========================================================
                 */
                DataTable PassengerDataTable =
                    _foreignServerDataMapper
                        .GetPassengerGraphDataAsync(
                            FromDateTime,
                            ToDateTime,
                            CorridorsFilterSelectedIndex + 1,
                            DirectionMode);

                /*
                 * ========================================================
                 * 3. CONVERT STATION DATA
                 * ========================================================
                 */
                List<StationAxisItem> stations =
                    new List<StationAxisItem>();

                foreach (DataRow row
                         in StationAxiesTable.Rows)
                {
                    stations.Add(
                        new StationAxisItem
                        {
                            StationIndex =
                                Convert.ToInt32(
                                    row["StationIndex"]),

                            StationName =
                                row["StationName"]
                                    ?.ToString()
                                ?? string.Empty
                        });
                }

                /*
                 * ========================================================
                 * 4. CONVERT PASSENGER DATA
                 * ========================================================
                 */
                List<PassengerStationPoint> points =
                    new List<PassengerStationPoint>();

                foreach (DataRow row
                         in PassengerDataTable.Rows)
                {
                    points.Add(
                        new PassengerStationPoint
                        {
                            TrainNo =
                                row["TrainNo"]
                                    ?.ToString()
                                ?? string.Empty,

                            TripId =
                                Convert.ToInt32(
                                    row["TripId"]),

                            StationIndex =
                                Convert.ToInt32(
                                    row["StationIndex"]),

                            CurrentStation =
                                row["CurrentStation"]
                                    ?.ToString()
                                ?? string.Empty,

                            NextStation =
                                row["NextStation"]
                                    ?.ToString()
                                ?? string.Empty,

                            DDateTime =
                                Convert.ToDateTime(
                                    row["DDateTime"]),

                            TotalPassenger =
                                Convert.ToInt32(
                                    row["TotalPassenger"])
                        });
                }

                /*
                 * ========================================================
                 * 5. STORE COMPLETE STATION LIST
                 * ========================================================
                 */
                AllStationAxisItems =
                    stations
                        .OrderBy(x => x.StationIndex)
                        .ToList();

                AllStations =
                    AllStationAxisItems
                        .Select(x => x.StationName)
                        .ToList();

                RaisePropertyChanged(
                    "AllStations");

                /*
                 * ========================================================
                 * 6. BUILD COMPLETE STACKED SERIES
                 * ========================================================
                 *
                 * BuildSeries creates the full data set.
                 *
                 * It does NOT apply the station selection yet.
                 */
                BuildSeries(points);

                /*
                 * ========================================================
                 * 7. CREATE STATION MULTI SELECT ITEMS
                 * ========================================================
                 *
                 * First 4 stations are selected.
                 */
                BuildStationSelectionItems();

                /*
                 * ========================================================
                 * 8. APPLY DEFAULT STATION VISIBILITY
                 * ========================================================
                 */
                UpdateStationsVisibility();
            }
            catch (OperationCanceledException)
            {
                System.Diagnostics.Debug.WriteLine(
                    "Station chart refresh cancelled.");
            }
            catch (Exception ex)
            {
                System.Diagnostics.Debug.WriteLine(
                    "Station chart error: " +
                    ex);
            }
            finally
            {
                ShowBusyCursor = false;
            }
        }

        // ================================================================
        // BUILD STATION MULTI SELECT LIST
        // ================================================================

        private void BuildStationSelectionItems()
        {
            _IsUpdatingStationSelection = true;

            try
            {
                StationsItems.Clear();
                StationsFilterSelctedItems.Clear();

                var orderedStations =
                    AllStationAxisItems
                        .OrderBy(x => x.StationIndex)
                        .ToList();

                for (int i = 0;
                     i < orderedStations.Count;
                     i++)
                {
                    bool isSelected = i < 4;

                    string stationName =
                        orderedStations[i].StationName;

                    /*
                     * This is the same StringWithBool constructor pattern
                     * used by the working TimeSeriesPsgCntView page.
                     */
                    StationsItems.Add(
                        new StringWithBool(
                            stationName,
                            isSelected));

                    /*
                     * SelectedItems contains the station names that the
                     * MultiSelectComboBox should show as selected.
                     */
                    if (isSelected)
                    {
                        StationsFilterSelctedItems.Add(
                            stationName);
                    }
                }
            }
            finally
            {
                _IsUpdatingStationSelection = false;
            }
        }

        // ================================================================
        // STATION DROPDOWN CLOSED
        // ================================================================

        /*
         * This is exactly the same concept as the working reference:
         *
         * StationsComboBoxDropDownClosed()
         *
         * Only update the chart if the selected station list actually
         * changed.
         */
        public void StationsComboBoxDropDownClosed()
        {
            if (_IsUpdatingStationSelection)
            {
                return;
            }

            if (IsCollectionNullOrEmpty(
                    StationsFilterSelctedItems) == false)
            {
                if (AreBothListsAreEqual(
                        StationsFilterSelctedItems,
                        StationsFilterSelectedItemsBeforeOpeningDropDown)
                    == false)
                {
                    UpdateStationsVisibility();
                }

                StationsFilterSelectedItemsBeforeOpeningDropDown =
                    null;
            }
            else
            {
                /*
                 * Same behavior as the working reference:
                 * if nothing is selected, update the chart.
                 *
                 * UpdateStationsVisibility() will show all stations
                 * when the selected collection is empty.
                 */
                UpdateStationsVisibility();

                StationsFilterSelectedItemsBeforeOpeningDropDown =
                    null;
            }
        }

        // ================================================================
        // COLLECTION EMPTY CHECK
        // ================================================================

        public static bool IsCollectionNullOrEmpty<T>(
            IEnumerable<T> list)
        {
            if (list != null &&
                list.Count() > 0)
            {
                return false;
            }

            return true;
        }

        // ================================================================
        // COMPARE TWO SELECTION LISTS
        // ================================================================

        private bool AreBothListsAreEqual<T>(
            IEnumerable<T> list1,
            IEnumerable<T> list2)
        {
            /*
             * Both null/empty means no change.
             */
            if (list1 == null && list2 == null)
            {
                return true;
            }

            if (list1 == null)
            {
                return false;
            }

            if (list2 == null)
            {
                return false;
            }

            /*
             * A HashSet comparison is simpler and faster than nested
             * loops used in the original reference.
             *
             * Station names are unique in the station axis.
             */
            var first =
                new HashSet<T>(list1);

            var second =
                new HashSet<T>(list2);

            return first.SetEquals(second);
        }

        // ================================================================
        // BUILD COMPLETE STACKED SERIES
        // ================================================================

        private void BuildSeries(
            List<PassengerStationPoint> points)
        {
            /*
             * Clear old data.
             */
            SeriesMap.Clear();

            OriginalSeriesValues.Clear();

            /*
             * Build complete axis first.
             */
            BuildAxis(
                AllStationAxisItems);

            /*
             * Group by Train + Trip.
             *
             * One StackedColumnSeries = one Train/Trip.
             */
            var groups =
                points
                    .OrderBy(x => x.DDateTime)
                    .GroupBy(x => new
                    {
                        x.TrainNo,
                        x.TripId
                    })
                    .OrderBy(x =>
                        x.Min(y => y.DDateTime))
                    .ToList();

            var series =
                new List<ISeries>();

            var palette =
                GetPalette();

            int colorIndex = 0;

            /*
             * Complete station list.
             *
             * Every series gets a value for every station.
             */
            var allStations =
                AllStationAxisItems
                    .OrderBy(x => x.StationIndex)
                    .ToList();

            foreach (var group in groups)
            {
                string trainNo =
                    group.Key.TrainNo;

                DateTime time =
                    group.Min(
                        x => x.DDateTime);

                /*
                 * Name is intentionally retained.
                 *
                 * This is what LiveCharts uses for the legend.
                 */
                string seriesName =
                    $"{time:HH:mm} {trainNo}";

                /*
                 * Build lookup:
                 *
                 * StationIndex -> PassengerStationPoint
                 *
                 * This avoids FirstOrDefault() for every station.
                 */
                var stationLookup =
                    group
                        .GroupBy(
                            x => x.StationIndex)
                        .ToDictionary(
                            g => g.Key,
                            g => g.First());

                var originalValues =
                    new List<PassengerCountStackedPoint>();

                /*
                 * Create COMPLETE values.
                 *
                 * These values are never deleted when a station is
                 * selected/unselected.
                 */
                foreach (var station
                         in allStations)
                {
                    if (stationLookup.TryGetValue(
                            station.StationIndex,
                            out PassengerStationPoint data))
                    {
                        originalValues.Add(
                            new PassengerCountStackedPoint
                            {
                                StationIndex =
                                    station.StationIndex,

                                StationName =
                                    station.StationName,

                                TrainNo =
                                    trainNo,

                                DDateTime =
                                    data.DDateTime,

                                PassengerCount =
                                    data.TotalPassenger
                            });
                    }
                    else
                    {
                        /*
                         * Keep a zero value so every train has the same
                         * station positions.
                         */
                        originalValues.Add(
                            new PassengerCountStackedPoint
                            {
                                StationIndex =
                                    station.StationIndex,

                                StationName =
                                    station.StationName,

                                TrainNo =
                                    trainNo,

                                DDateTime =
                                    time,

                                PassengerCount = 0
                            });
                    }
                }

                PassengerCountStackedPoint[] originalArray =
                    originalValues.ToArray();

                /*
                 * Store original values.
                 *
                 * This is the key to avoiding database calls when the
                 * station filter changes.
                 */
                OriginalSeriesValues[seriesName] =
                    originalArray;

                SKColor lineColor =
                    palette[
                        colorIndex %
                        palette.Count];

                var columnSeries =
                    new StackedColumnSeries<
                        PassengerCountStackedPoint>
                    {
                        /*
                         * KEEP Name.
                         *
                         * Removing Name would also remove the useful
                         * legend text.
                         */
                        Name = seriesName,

                        /*
                         * Initially show all values.
                         *
                         * UpdateStationsVisibility() immediately
                         * replaces this with the first four stations.
                         */
                        Values = originalArray,

                        Fill =
                            new SolidColorPaint(
                                lineColor),

                        Stroke = null,

                        MaxBarWidth = 100,

                        DataLabelsPaint =
                            new SolidColorPaint(
                                SKColors.White),

                        DataLabelsSize = 11,

                        /*
                         * Display inside each stacked segment:
                         *
                         * 07:01 TS023 178
                         */
                        DataLabelsFormatter =
                            point =>
                            {
                                if (point.Model
                                    is PassengerCountStackedPoint data)
                                {
                                    if (data.PassengerCount <= 0)
                                    {
                                        return string.Empty;
                                    }

                                    return
                                        $"{data.DDateTime:HH:mm} " +
                                        $"{data.TrainNo} " +
                                        $"{data.PassengerCount}";
                                }

                                return string.Empty;
                            },

                        /*
                         * Tooltip X label.
                         *
                         * The series Name remains available for the
                         * legend, but this formatter controls the X-axis
                         * part of the tooltip.
                         */
                        XToolTipLabelFormatter =
                            chartPoint =>
                            {
                                if (chartPoint.Model
                                    is PassengerCountStackedPoint data)
                                {
                                    return data.StationName;
                                }

                                return string.Empty;
                            },

                        /*
                         * Tooltip Y label.
                         *
                         * This is the passenger information shown for
                         * the selected stacked segment.
                         */
                        YToolTipLabelFormatter =
                            chartPoint =>
                            {
                                if (chartPoint.Model
                                    is PassengerCountStackedPoint data)
                                {
                                    return
                                        $"Time: " +
                                        $"{data.DDateTime:HH:mm}\n" +
                                        $"Train: " +
                                        $"{data.TrainNo}\n" +
                                        $"Passengers: " +
                                        $"{data.PassengerCount}";
                                }

                                return string.Empty;
                            }
                    };

                series.Add(
                    columnSeries);

                SeriesMap[seriesName] =
                    columnSeries;

                colorIndex++;
            }

            /*
             * Set the complete series collection only once.
             *
             * Later station filtering does not recreate the series.
             */
            Series =
                series.ToArray();
        }

        // ================================================================
        // UPDATE STATION VISIBILITY
        // ================================================================

        private void UpdateStationsVisibility()
        {
            if (AllStationAxisItems == null ||
                AllStationAxisItems.Count == 0)
            {
                return;
            }

            /*
             * ============================================================
             * 1. GET SELECTED STATION NAMES
             * ============================================================
             */
            var selectedStations =
                new HashSet<string>(
                    StationsFilterSelctedItems
                    ?? Enumerable.Empty<string>(),
                    StringComparer.OrdinalIgnoreCase);

            /*
             * Same usable behavior as the reference page:
             *
             * If selection is empty, show all stations.
             */
            var visibleStations =
                selectedStations.Count == 0
                    ? AllStationAxisItems
                        .OrderBy(x => x.StationIndex)
                        .ToList()
                    : AllStationAxisItems
                        .Where(x =>
                            selectedStations.Contains(
                                x.StationName))
                        .OrderBy(x => x.StationIndex)
                        .ToList();

            /*
             * ============================================================
             * 2. UPDATE X-AXIS
             * ============================================================
             *
             * For stacked columns the Values index determines the X
             * position. Therefore the values must also be rebuilt using
             * the SAME visible station order.
             */
            if (XAxes == null ||
                XAxes.Length == 0)
            {
                BuildAxis(
                    visibleStations);
            }
            else
            {
                XAxes[0].Labels =
                    visibleStations
                        .Select(x =>
                            x.StationName)
                        .ToArray();

                /*
                 * Notify LiveCharts/WPF that the axis property changed.
                 *
                 * Creating a new Axis[] is safer than relying on an
                 * internal mutation notification.
                 */
                XAxes =
                    new Axis[]
                    {
                        new Axis
                        {
                            Name = "Stations",

                            Labels =
                                visibleStations
                                    .Select(x =>
                                        x.StationName)
                                    .ToArray(),

                            LabelsRotation = 90,

                            TextSize = 10,

                            MinStep = 1,

                            UnitWidth = 1,

                            ForceStepToMin = true,

                            SeparatorsPaint =
                                new SolidColorPaint(
                                    new SKColor(
                                        225,
                                        225,
                                        225))
                        }
                    };
            }

            /*
             * ============================================================
             * 3. REBUILD ONLY VISIBLE VALUES
             * ============================================================
             *
             * IMPORTANT:
             *
             * We DO NOT query the database.
             *
             * We DO NOT recreate the ISeries objects.
             *
             * We only replace the Values for each existing stacked
             * series using OriginalSeriesValues.
             */
            if (Series == null)
            {
                return;
            }

            foreach (var stackedSeries
                     in Series.OfType<
                         StackedColumnSeries<
                             PassengerCountStackedPoint>>())
            {
                string seriesName =
                    stackedSeries.Name?.ToString()
                    ?? string.Empty;

                if (!OriginalSeriesValues.TryGetValue(
                        seriesName,
                        out PassengerCountStackedPoint[]
                            originalValues))
                {
                    continue;
                }

                /*
                 * Dictionary makes station lookup O(1).
                 */
                var originalLookup =
                    originalValues
                        .ToDictionary(
                            x => x.StationIndex,
                            x => x);

                var newValues =
                    new List<
                        PassengerCountStackedPoint>();

                /*
                 * IMPORTANT:
                 *
                 * Add values in exactly the same order as X-axis labels.
                 *
                 * Example:
                 *
                 * Selected:
                 * Station 1
                 * Station 4
                 * Station 7
                 *
                 * X-axis:
                 * [Station1, Station4, Station7]
                 *
                 * Values:
                 * [value1, value4, value7]
                 */
                foreach (var station
                         in visibleStations)
                {
                    if (originalLookup.TryGetValue(
                            station.StationIndex,
                            out PassengerCountStackedPoint
                                point))
                    {
                        newValues.Add(
                            point);
                    }
                }

                /*
                 * Replace visible values.
                 *
                 * The original values remain safely stored in
                 * OriginalSeriesValues.
                 */
                stackedSeries.Values =
                    newValues.ToArray();
            }

            /*
             * Request chart update.
             *
             * Series is still the same ISeries[] reference, so explicitly
             * notify the binding after changing Values.
             */
            RaisePropertyChanged(
                "Series");
        }

IMPORTANT IMPLEMENTATION CORRECTION

In BuildStationSelectionItems(), use the constructor form already
demonstrated by your working reference:

    new StringWithBool(stationName, isSelected)

Therefore the final method to use is:

private void BuildStationSelectionItems()
{
    _IsUpdatingStationSelection = true;

    try
    {
        StationsItems.Clear();
        StationsFilterSelctedItems.Clear();

        var orderedStations =
            AllStationAxisItems
                .OrderBy(x => x.StationIndex)
                .ToList();

        for (int i = 0;
             i < orderedStations.Count;
             i++)
        {
            bool isSelected = i < 4;

            string stationName =
                orderedStations[i].StationName;

            StationsItems.Add(
                new StringWithBool(
                    stationName,
                    isSelected));

            if (isSelected)
            {
                StationsFilterSelctedItems.Add(
                    stationName);
            }
        }
    }
    finally
    {
        _IsUpdatingStationSelection = false;
    }
}

IMPORTANT:
Use the above method as the actual BuildStationSelectionItems()
implementation.

The helper method SetStringWithBoolValue() and the
BuildStationSelectionItemsActual() method are documentation only and
should NOT be kept in the final class.

WHY THIS IS BETTER FOR THE STATION WISE STACKED BAR PAGE
======================================================================

The working reference page already demonstrates that station selection
can be handled by changing the existing chart data rather than querying
the database again. The reference specifically uses StationsItems,
StationsFilterSelctedItems and the dropdown open/close callbacks.
See the original reference XAML at lines 2-15 and the corresponding
ViewModel properties at lines 303-356. fileciteturn0file0L303-L356

The reference also saves the selected stations when the dropdown opens
and calls UpdateStationsVisibility() only when the dropdown closes and
the selection changed. fileciteturn0file0L511-L540

For Station Wise, the same pattern is applied to StackedColumnSeries:
the complete train/station values are cached, and station selection only
changes the visible Values array. This is preferable to calling
GetPassengerGraphDataAsync() for every station selection.
